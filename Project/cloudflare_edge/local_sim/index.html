How this works: Each button click sends a real HTTP request to the local Node.js server (local_sim/server.js). The server loads edge_handler.wasm (compiled from C++) using the Node.js WebAssembly API, writes the request data into WASM linear memory, calls edgeHandle() (a C++ function), reads the result back from memory, and returns it as JSON. This is identical to how a real Cloudflare Worker would invoke the WASM module at the edge.
